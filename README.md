# ADInfo

This is AI generated code.  

I was looking for a way to replace some of the functionallaty of DameWare after they raised prices.

The user tab will display all users accounts in Active Directory.  The columns are account name, display name, last login, password last set, if the password is set to never expire, and when the current password will expire.  The Domain password policy is also shown at the top of the page.

Under the computers tab, it will show the computer name, OS, last login and days since last login.  This feature will help to show what comptuer accounts are not in use and help with removal of removed computers.
